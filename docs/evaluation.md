# Evaluation and Reproducibility

The canonical machine-readable report is
[`evaluation_results.json`](evaluation_results.json). It was generated by:

```powershell
.\.venv\Scripts\python.exe scripts\run_evaluation.py --seed 42
```

## Protocol

- Dataset: 12,000 deterministic synthetic transactions, seed 42.
- Train: 7,739 rows before simulated day 21.
- Validation: 1,668 rows from day 21 through day 24.
- Test: 2,593 rows from day 25 through day 30.
- Positive test support: 153 transactions.
- Threshold selection: validation F1 only; test labels never choose thresholds.
- Flat features: amount, time-of-day, payee/instrument type, account age.
- Graph features: strictly prior user/device/instrument/IP and cadence counters.

## Generalization and adversarial checks

Holding archetype H out of model fitting removed 10 training rows. Against test
negatives plus 73 H positives, the graph LR measured precision 0.6239, recall
1.0, F1 0.7684, and PR-AUC 0.7875.

The fixed selected model was also evaluated after deterministic feature-space
evasions:

| Scenario | Recall | F1 | PR-AUC |
|---|---:|---:|---:|
| Original | 1.0000 | 0.9134 | 0.9040 |
| 75% infrastructure dilution | 0.4902 | 0.6198 | 0.8109 |
| Timing smear | 1.0000 | 0.8895 | 0.8943 |
| Combined evasion | 0.4575 | 0.5882 | 0.7846 |

Infrastructure dilution is the clearest measured weakness. This result is kept
visible because it is more decision-useful than the attractive original AUC.
